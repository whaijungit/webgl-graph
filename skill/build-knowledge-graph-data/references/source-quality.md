# Source Quality and Uncertainty

1. Prefer primary sources, official archives, standards bodies, peer-reviewed
   literature, official product documentation, or the user's supplied data.
2. Use encyclopedias and secondary summaries to locate terminology, then verify
   critical names, numbers, dates, ranks, and directions elsewhere.
3. Keep a compact source list with URLs, titles, and access date when facts are
   time-sensitive.
4. Use multiple sources for disputed hierarchy, authorship, chronology, or
   biological causality.
5. Encode uncertainty visibly:
   - label variant names: `Name A（一作 Name B）`;
   - use `reported` or `disputed` in a note/report;
   - omit claims that cannot be sourced.
6. Never infer sensitive personal attributes unless the user explicitly requires
   them and the source supports it.
7. Do not treat search-result snippets as final evidence when the underlying page
   can be opened and checked.
