# 大图压测

主页面通过 URL 查询参数选择合成数据规模，不创建额外控制面板。

## 固定预设

```text
http://127.0.0.1:4317/?preset=100k
http://127.0.0.1:4317/?preset=300k
http://127.0.0.1:4317/?preset=600k
http://127.0.0.1:4317/?preset=1m
```

| 预设 | 节点 | 边 | 社区 |
| --- | ---: | ---: | ---: |
| `100k` | 100,000 | 200,000 | 48 |
| `300k` | 300,000 | 600,000 | 64 |
| `600k` | 600,000 | 1,200,000 | 96 |
| `1m` | 1,000,000 | 2,000,000 | 128 |

## 自定义数量

`nodes`、`edges`、`clusters` 和 `seed` 可覆盖预设：

```text
http://127.0.0.1:4317/?preset=100k&nodes=150000&edges=350000
```

## 持续渲染

默认采用按需渲染。增加 `continuous=1` 可连续提交帧并采集 FPS：

```text
http://127.0.0.1:4317/?preset=300k&continuous=1
```

目标帧率通过 `fps` 设置，范围为 30～60：

```text
http://127.0.0.1:4317/?preset=300k&continuous=1&fps=60
```

## 运行指标

数据装载完成后可在浏览器控制台查看：

```js
graphStressInfo;
graphLastFrame;
graphMetrics;
```

- `graphStressInfo`：节点、边、Worker 生成、加载和上传耗时。
- `graphLastFrame`：最近一帧 CPU 耗时和 draw call 数量。
- `graphMetrics`：持续渲染或交互时的 FPS 采样。
- 页面左下角的 `stats.js` 面板由同一个 GraphView 帧完成事件驱动，可直接观察当前实际 FPS。

大图会省略逐节点标签和逐边关系字符串，避免测试数据本身产生数 GB 的 JavaScript 对象。

## 60 FPS 大图策略

节点数达到 100,000 后自动启用大图渲染路径：

- 节点由每节点四个顶点的图标四边形切换为每节点一个顶点的 Point Sprite。
- Point Sprite 通过 `uNodeShape` 支持全部节点形状：图片模式根据 `nodeIconIds` 绘制 8 种高对比度简化图标，其他形状使用轻量片元 SDF。
- Point Sprite 的远景屏幕尺寸以可调 `minimumNodeSize` 为下限，默认按权重映射到约 3～9px；放大后继续按权重增长，在显示全部视口节点的同时控制百万点片元成本。
- 选中节点和直接邻居继续使用当前 Point Sprite 形状、原颜色和原尺寸语义，只放大、提亮并调整绘制顺序；其他节点降低透明度。
- 形状切换只增加 `uNodeShape` uniform，不增加 draw call 或 Point Sprite 提交数量。
- 当前视口内的全部可见节点按权重顺序写入紧凑 `Uint32Array`，不再按节点预算抽样；当前焦点最后提交，直接邻居紧随其后。
- 边先按端点和预算抽样，再压缩到动态实例缓冲；不可见边不再参与顶点着色。
- 目标端方向箭头复用边实例和同一次 draw call；每条实例只增加 3 个静态三角顶点，关闭箭头时不提交这些顶点。
- 选中节点和全部直接邻居强制加入节点索引，选中节点的全部关联边绕过普通边预算。
- 节点尺寸与 `minimumNodeSize` 随相机放大平滑增长并限制为 2.5 倍，避免缩放时节点相对越来越小。
- 邻域标记属性使用归一化 `UNSIGNED_BYTE`，上传值必须写成 `0/255`；写成 `0/1` 时 GPU 只能读到约 `0.0039`，会导致大图关联节点被误判为非关联节点并压暗。
- 大图普通边预算上限为 6,000；交互质量降级时可以继续降到 4,000。
- 所有已绘制边的端点会强制加入节点索引，避免出现只有边、没有端点图标的缺失。
- Point Sprite 属性按权重排序后的实例顺序上传，因此索引缓冲必须保存实例索引，不能直接保存业务节点 ID。
- CPU 只维护 TypedArray 和 WebGL buffer，不在每帧创建节点或边业务对象。

小图仍使用完整节点形状、原始边颜色和全部边，不进入上述大图简化路径。
